# IP Informer

Нативный компактный виджет для macOS, который показывает внешний IPv4 одной строкой на полностью прозрачном фоне поверх всех окон. На каждом подключённом дисплее создаётся синхронизированная копия виджета. При смене адреса все виджеты мигают и приложение воспроизводит звук.

## Сборка

```sh
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open "dist/IP Informer.app"
```

Интервал проверки меняется через значок IP Informer в строке меню → **Настройки…**. Доступны значения от 5 секунд до 10 минут. Там же можно включить запуск при входе в macOS.

Значок IP Informer в строке меню открывает компактную панель программ. Каждая непустая группа занимает одну строку своего цвета с иконками программ; программы без группы показаны в нейтральной строке. Название появляется через четверть секунды после наведения; левый щелчок запускает программу или переводит уже запущенную на передний план. Правый щелчок открывает меню переноса в другую группу или «Без группы» и удаления программы из IP Informer. Удаление убирает связанные с ней правила перенаправления, но не удаляет `.app` с Mac. Если в строке больше пяти программ, значки плавно прокручиваются колесом мыши или жестом трекпада; стрелки также перемещают ленту, а число под «+» показывает общее количество. Кнопка «+» добавляет в строку одну или несколько программ; уже добавленные программы пропускаются. IPv4 остаётся в плавающем виджете.

В настройках доступно несколько встроенных источников определения IPv4. При каждой проверке используется следующий включённый источник по кругу; если он недоступен, оставшиеся источники проверяются как резервные. Позиция очереди сохраняется между запусками. Можно отключать источники и добавлять собственные URL, возвращающие IPv4 обычным текстом либо в JSON-поле `ip`. Инструкция для VPS встроена в окно настроек и продублирована в [VPS_SETUP.md](VPS_SETUP.md).

Вкладка **sing-box** содержит основную JSON-конфигурацию: DNS, серверы, цепочки и все `outbound`. Перед сохранением показывается построчное сравнение; 30 последних версий доступны в истории. Вкладка **Профили** содержит профили маршрутов. Во вкладке **Программы** приложения показаны по группам; у группы есть цвет, сворачиваемый список и отдельная кнопка изменения названия, цвета и маршрута. Можно выбрать сразу несколько `.app`; уже добавленные программы пропускаются. Новая группа появляется первой. Внутри группы действует её маршрут; сохранённый личный профиль применяется после переноса программы в «Без группы». IP Informer добавляется в список автоматически и использует `proxy`, если такой outbound существует. Маршрут применяется также к вспомогательным процессам внутри выбранной `.app`. Отдельный раздел **Команды терминала** назначает маршрут исполняемым файлам вроде `ssh` и разрешает локальные IPv4 напрямую; правило действует из любого терминала. Подробнее: [NETWORK_ROUTING_SETUP.md](NETWORK_ROUTING_SETUP.md).

Во вкладке **sing-box** можно экспортировать все настройки в зашифрованный паролем файл и восстановить их на другом Mac. В архив входят JSON, история версий, профили, группы, программы, команды, перенаправления, источники IP, интервал проверки, видимость и положения виджетов, а также настройка автозапуска. Сами `.app` и системная служба в архив не входят. При восстановлении программы ищутся по идентификатору, а команды — по пути; ненайденные остаются выключенными до повторного указания пути.

Там же находится мастер **Новый сервер…** для нового Linux VPS: он создаёт клиентский и серверный JSON, проверяет их установленной версией sing-box и устанавливает сервер по SSH. Для VLESS + Reality, Shadowsocks 2022, VMess, Trojan, Hysteria2 и AnyTLS пара создаётся автоматически. Три последних протокола используют TLS: мастер настраивает ACME или встраивает выбранные PEM-сертификат и закрытый ключ в JSON. Остальные совместимые inbound показаны как ручной режим с проверкой обоих JSON; ссылки на внешние файлы в них отклоняются. Endpoint не предлагаются как готовая пара клиент–сервер. Несколько клиентских подключений сохраняются как профили: их можно назначать программам и группам или переключать общий маршрут. У каждого подключения доступны **Клиентский JSON**, **Серверный JSON** и **Поделиться QRS**. Серверные ключи хранятся в Keychain и входят в зашифрованный архив.

У сохранённого подключения кнопка **Поделиться QRS** показывает циклический QR для официального sing-box для Android 1.13 или новее. Откройте его сканер QR и дождитесь завершения импорта. Передаётся самостоятельный клиентский профиль с выбранным outbound, TUN и DNS только для IPv4; серверный JSON и остальные подключения не включаются. QR содержит клиентские данные доступа.

Пункт **Маршрут остальных программ** задаёт отдельный путь для приложений без назначенного профиля: любой outbound из основной конфигурации, **Только этот Mac** или **Без сети**. В двух последних вариантах localhost остаётся доступен.

Под общим маршрутом есть переключатель для встроенных веб-приложений WebKit. Он направляет Telegram Web Apps и встроенные веб-страницы других программ через outbound `proxy`, даже когда маршрут остальных программ ограничен. В разделе sing-box можно установить патч IP Informer 1.14.4-1: после этого добавление и перенос программ обновляют правила без обрыва открытых соединений. У программы можно включить выбор маршрута для дочерних команд, например `ssh` из iTerm; выбор запоминается для этой пары программы и команды. Пока патч активен, обновление движка до других версий отключено; есть кнопка возврата к официальной версии. Без патча изменение сетевых правил по-прежнему перезапускает sing-box.

У каждой программы есть отдельный переключатель **«Доступ к локальной сети напрямую»**. Он действует при любом маршруте, включая маршрут группы и «Без сети»: локальные IPv4 идут напрямую, а публичные адреса продолжают следовать выбранному маршруту.

При назначении или смене личного либо группового профиля внешний IP выбранного маршрута определяется и показывается рядом с программой во вкладке **Программы**. Обновляется только выбранный маршрут; проверку можно повторить вручную. Маршрутизируемые соединения и DNS используют IPv4, а IPv6-соединения отклоняются. Периодического опроса маршрутов нет. Основной компактный виджет по-прежнему показывает общесистемный внешний IPv4; только его изменение вызывает мигание и звук.

Каждый виджет можно перетаскивать за любое свободное место; позиция отдельно сохраняется для каждого дисплея. При подключении или отключении монитора набор виджетов обновляется автоматически. Первый полученный адрес считается исходным и не вызывает сигнал.

Интервал, список источников, включённые источники, пользовательские URL, положение на каждом мониторе и состояние «показаны/скрыты» сохраняются автоматически и применяются при следующем запуске. Автозапуск хранится системной службой macOS.
