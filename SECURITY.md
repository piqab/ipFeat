# Security Policy

## Supported versions

Security fixes are provided for the latest published release of ipFeat.
Older releases may not receive security fixes.

## Reporting a vulnerability

Please report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/piqab/ipFeat/security/advisories/new).

Do not open a public issue or pull request for an unpatched vulnerability.

Include the affected ipFeat version, macOS version, steps to reproduce,
the expected and observed behavior, and the potential impact. Redact
passwords, API keys, private keys, and credentials in client or server
configurations before attaching logs or files.

Reports involving traffic leaks, routing bypasses, local service
installation, configuration import or export, and the bundled sing-box
patch are welcome. If you are unsure whether an issue belongs to ipFeat
or upstream sing-box, report it here first.

We will review the report and coordinate a fix and public disclosure
with the reporter. We do not promise a fixed response or release date.
