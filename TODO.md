# Патч sing-box для правил программ и дочерних команд

Полный контракт и требования для переноса на следующие версии: [SING_BOX_PATCH.md](SING_BOX_PATCH.md).

Реализация находится в `patches/sing-box-1.14.4-ipinformer-2.patch`. Исходный код закреплён на `v1.14.4` (`c005f35300ce76427dc285481ec5695f5b179cd2`); сборка — `scripts/build-patched-sing-box.sh`. Патч относится только к локальному движку macOS, серверный sing-box остаётся официальным.

Готово:

- Таблица правил программ меняется через отдельный JSON без перезапуска TUN. Существующие соединения сохраняют выбранный маршрут; новые используют обновлённые правила.
- Для macOS sing-box определяет PID владельца сокета и проверяет цепочку родительских процессов. Ревизия 2 проходит через проверенный системный `/usr/bin/login` между iTerm2 и shell; при недоступном `proc_pidinfo` использует `kern.proc.pid` с проверкой PID и времени запуска. Неоднозначная атрибуция не даёт унаследовать маршрут чужого приложения.
- В настройках каждой программы можно включить запрос маршрута для дочерних команд. Ответ сохраняется для пары «программа + путь команды». Явное правило дочерней команды имеет приоритет перед глобальным правилом команды; глобальное — перед маршрутом программы и общим маршрутом.
- Запросы ограничены по времени, количеству и размеру; при недоступном IP Informer применяется обычное правило программы или группы. Частные IPv4-адреса не задерживаются запросом.
- Патч устанавливается отдельно от официального бинарника, проверяется SHA-256 и `sing-box check`, отключает автоматические обновления движка и имеет кнопку возврата.

Автоматические проверки: Go-тесты атрибуции и правил, Swift-тесты генератора и совместимости обычного JSON, локальный тест смены правила при сохранении открытого TCP-соединения.

После установки на рабочий Mac проверить вручную:

- `ssh` из iTerm, вложенного shell и другого терминала, TCP и UDP; запрос должен относиться к правильной программе.
- Сохранение соединений других приложений при добавлении и перемещении программы.
- Локальные IPv4-адреса через физический интерфейс и публичные IPv4-адреса через выбранный proxy.
- Возврат к официальному бинарнику и повторный запуск сетевой службы.

Бинарник патча нельзя обновлять на следующую версию sing-box без отдельной адаптации и повторной проверки исходного патча.
